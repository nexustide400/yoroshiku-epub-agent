# 最小サンプル

このサンプルを実行するときは、縦長の表紙画像を `cover.jpg` という名前でこのフォルダへ追加してください。表紙画像そのものは第三者の権利やAI生成区分を曖昧にしないため、リポジトリには同梱していません。

`build-config.example.json` は設定スキーマの説明用です。通常の利用ではCodexが `scan` の結果を確認して `.kdp-work/build-config.json` を作るため、手作業で設定を書く必要はありません。

`book-info.md` はEPUBに埋め込む書誌情報だけの入力例です。KDP画面固有の入力項目は含めません。
